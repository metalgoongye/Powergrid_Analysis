# 변수·데이터 명세 (Data Provenance)

논문·보고서의 "데이터 및 변수" 절을 쓰기 위한 명세표. 모형 변수(모수)마다
**무엇을, 어디서, 언제 받아, 어떻게 가공해, 어떤 값을 얻었는지**를 기록한다.

- 기계 검증이 걸린 정본은 `config/sources.yml`(표형)과 `config/layers.yml`
  (공간)이고, 이 문서는 그 위에 얹는 논문용 요약이다. 충돌 시 정본이 우선.
- 추정이 하나 끝날 때마다 이 문서를 갱신한다. 값은 산출 시점 기준이며
  원자료 갱신 시 재계산한다. 모든 수치의 계산 주체는 `scripts/`의 코드다.
