# 실증분석 노트 — 손으로 따라가며 읽는 작업 기록

모델링 노트(modeling_note v2.2)의 실증 편입니다. 연구절차 순서대로, 각 분석이
**무엇을 / 왜 / 어떻게 / 결과 / 주의**의 틀로 기록됩니다. 분석이 진행될 때마다
이 문서를 갱신하고, 전체 분석이 끝나면 모델링 노트처럼 쉬운 용어의 워드 문서로
따로 뽑습니다. (갱신 규칙: CLAUDE.md)

- 분석 기준년: **2024** (에너지·판매·고용·소득 = 2024, 공간자료 = 2024-12-04본)
- 모든 수치는 스크립트 산출물에서 온 것이며, 손으로 옮겨 적은 값이 없습니다.
- 용어가 낯설면 맨 끝 **부록 B 용어집**부터 보세요.

## 0. 이 연구의 데이터 작업이 답해야 하는 질문

후생모형은 실증에서 네 숫자(λ, σ(Z), s, μ)와 캘리브레이션 상수(권역 수요 Q,
가구소비 e, 임금 w 등)를 받습니다. 1단계의 목표는 그중 **수요의 공간 분포**를
만드는 것입니다: "전국 어디에서 전기가 얼마나 쓰이는가"를 100m 격자 위에
올리는 작업. 이것이 권역 수요 Q_z와 신호 보존율 σ(Z)의 재료가 됩니다.

원재료는 셋입니다.

| 재료 | 가진 정보 | 못 가진 정보 |
|---|---|---|
| 건물에너지 공개본 (필지별 월별 kWh) | 사용량 + 지번 | **좌표 없음**, 용도 없음 |
| 연속지적도 (전국 3,971만 필지) | 필지 위치(폴리곤) + PNU | 사용량 없음 |
| 한전 판매전력량 (시군구×계약종별) | 완전한 총량(회계) | 공간 분포 없음 |

1단계의 모든 분석은 결국 이 셋을 잇는 작업입니다: 에너지에 **좌표를 붙이고**
(지적도), 그 결과가 **믿을 만한지 채점**하고(판매통계), 어긋난 만큼 **보정**
합니다.

## 1. 데이터 반입 규율 — 분석 전에 한 일들

**방법**: 모든 파일은 받는 즉시 ① 구조 검사(컬럼·레이어·건수를 스크립트로 집계)
② 내용 검사(공표 통계와 규모 대조) ③ 레지스트리 등록(config/layers.yml·
sources.yml) ④ `validate_layers.py` 통과 확인을 거칩니다.

**이 규율이 실제로 잡아낸 것들**:
- GIS건물통합이라며 받은 파일이 실은 치안시설 504건짜리 테마 추출물 → 반려
- 경기 연속지적 zip의 중간 구간 손상(30개 멤버 중 15개) → 재다운로드
- 다운로드 중복 12건 → SHA256 해시로 내용 동일 확인 후에만 삭제
- 2026년본 건물통합(통합시도 신코드) → 2024-12-04본으로 교체해 코드 체계 통일

**현재 레지스트리**: 검증 OK 69 · FAIL 0 (gpkg 26레이어, 행정경계 3종,

> 의문: 왜 이렇게까지 하나?
> 뒤 단계의 모든 숫자는 이 파일들에서 나옵니다. 반입 시점에 틀린 파일을
> 걸러내는 비용은 몇 분이고, 분석 후에 발견하는 비용은 전체 재계산입니다.
> 실제로 위 네 건 모두 "분석에 쓰기 전에" 걸렸습니다.

## 2. PNU 조인 — 에너지에 좌표 붙이기

**스크립트**: `scripts/s1_pnu_join_rate.py` → `out/public/s1_join_rate_202412.csv`

**무엇을**: 에너지 레코드(지번)와 지적도 필지를 **PNU**로 잇습니다. PNU는
필지의 전국 유일 주민번호 같은 19자리 코드입니다:

```
시군구코드(5) + 법정동코드(5) + 산구분(1) + 본번(4) + 부번(4)
예: 1138010700 + 1 + 0598 + 0026  = 서울 은평구 응암동 598-26 (대지)
```

에너지 파일에는 이 다섯 조각이 따로따로 들어 있어서 이어 붙이면 PNU가 되고,
지적도에는 PNU가 완성형으로 들어 있습니다. 산구분만 변환이 필요합니다
(에너지의 0/1 → PNU의 1/2. '산 598-26'과 '598-26'은 다른 필지입니다).

**왜**: 공개본에 좌표가 없으므로, 좌표를 가진 지적도에 붙어야만 지도가 됩니다.

**결과 (2024-12)**: 레코드 기준 **96.16%**, 사용량 기준 **93.42%** 조인 성공.
시도별 93.3~97.8%로 고릅니다.

**주의**: 사용량 기준이 레코드 기준보다 ~3%p 낮다 = 미조인이 대형 수용가 쪽에
치우쳐 있다(울산 89.2%가 최저 — 산단 지역 패턴). 미조인 3.8%의 원인 분해는
정제 과제로 남아 있습니다(§8).

## 3. 24개월 추이 — 한 달의 결과가 우연이 아닌지

**스크립트**: `scripts/s1_join_trend.py` → `out/public/s1_join_trend.csv`

**방법의 요점**: 매달 지적도(3,971만 필지)를 다시 읽으면 수십 분×24가
낭비됩니다. 그래서 2패스 구조를 썼습니다 — ① 전 월을 훑어 고유 PNU 전집
(165만)을 만들고, ② 지적 PNU와 한 번만 교차해 "조인 성공 집합"을 만든 뒤,
③ 월별로 다시 훑으며 그 집합에 대조만 합니다.

**결과**: 조인율이 연중 96%대로 안정. 그리고 세 가지 구조 신호 —

1. **2024-10 수록 확장**: 고유 PNU +79,179개 점프, 조인율 96.9→96.15% 단차.
   공개본의 수록 범위가 이때 넓어졌습니다. 월간 비교 시 이 앞뒤를 섞지 말 것.
2. **지적 vintage 드리프트**: 지적도 기준일(2024-12-04) 이후 생긴 필지는
   지적도에 없으므로, 2025년으로 갈수록 조인율이 완만히 하락(2025-12: 94.5%).
   기준년을 2024로 고정한 근거 중 하나.
3. **공개본의 정체 확인**: 공개본 월 총량이 한전 판매의 "주택용+일반용"의
   95.1~95.7%와 연중 일치 → **공개본 = 건물계 부하(가구 + 서비스업 기업)**.
   산업용(월 ~23.7TWh)은 처음부터 안 들어 있습니다. 모형 언어로: 가구 e와
   기업 ε 중 서비스 부문은 실측, 제조 부문은 별도 배분 트랙(§8).

> 의문: 12월 커버리지가 1월보다 낮아 보이는 이유는?
> 판매통계는 검침(청구)월, 공개본은 사용월 기준입니다. 12월 하순 난방
> 사용이 1월 검침에 잡혀 통계상 1월이 부풀어 보입니다. 그래서 월별 비교는
> ±1개월 시차를 허용하고, 기본 비교는 연간 합으로 합니다.

## 5. 시군구 정합 검증 — 지도의 품질 성적표

**스크립트**: `scripts/s1_sgg_coverage.py` → `out/public/s1_sgg_coverage_2024.csv`

**무엇을**: 자치단체 229개 단위에서 "공개본 연간 합 ÷ 판매(주택+일반)" =
**커버리지**를 재고, 산포(R²)를 봅니다. 전국 평균(95.7%)만으로는 공간 편향 —
지역마다 다르게 빠졌는지 — 을 볼 수 없기 때문입니다.

**버그와 교훈**: 첫 실행에서 전북 커버리지가 1,315%가 나왔습니다. 원인은
한전 통계가 같은 해 안에서 "전라북도"(연초)와 "전북특별자치도"(개명 후)를
혼용해, 같은 시군구가 두 단위로 쪼개진 것(그래서 단위 수가 229가 아닌 243).
표기 정규화로 병합하자 정상화 — **"이상하게 큰 수치는 거의 항상 키(key)
문제"**라는 교훈.

**결과**:
- R²(로그) **0.974** — 공간 분포의 전반적 정합은 우수
- 커버리지 중위 86.4%, P10 66.9% ~ P90 112.8% — **균질하지 않음**
- 플래그 11곳(커버리지 <55% 또는 >130%, 부하 비중 3.2%): 저커버는
  접경 군부대(화천·양구·인제)·도서(옹진·신안), 초과는 군포(216%)·하남·태안 등
- 보정 전 상태로 모형에 넣으면 비수도권/수도권 수요비 Q₂/Q₁이 **−3.9% 왜곡**

**분모 실험**: 분모에 교육·심야까지 넣어보면 전체적으로 더 안 맞음(중위
78.5%) → 공개본은 교육·심야를 온전히 담지 않음 → 작업 정의는 "주택+일반
대비"로 확정.

**꼬리의 원인 후보** (가설, 진단 예정 — references/key-evidence.md §4):
분모 문제(한전 사업소 관할 경계) / 구성 불일치(공개본에 산업용 검침 혼입) /
특수 수용가 미포착(군부대 등).

## 6. 보정(레이킹) 설계 — "버리지 않고, 재서 맞춘다"

**용어**: 레이킹(raking) = 미시 데이터의 분포 모양은 유지하면서 합계만 믿을
만한 공표 통계에 맞추는 비례 조정. WorldPop(격자 인구), 배출 인벤토리,
서베이 가중치 보정(Deville and Särndal 1992)이 같은 계열입니다.

**왜 "이상한 시군구 버리기"가 아닌가**: 이 연구의 산출물은 회귀계수가 아니라
**전국 완비 지도**입니다. 버리면 ① 권역 수요합에 구멍이 나고 ② 빠지는 곳이
접경·도서·산단으로 무작위가 아니어서 측정오차가 **선택편향**으로 바뀝니다.
측정오차는 크기를 재서 보고할 수 있지만 선택편향은 정량화가 안 됩니다.

**규율 3개** (이게 없으면 보정은 비과학이 됩니다):
1. **신뢰구간에만 적용** — 커버리지 55~130%인 218곳만 계수(=100/커버리지)를
   곱하고, 플래그 11곳은 틀린 잣대에 맞추지 않도록 원값+기록으로 격리
2. **용도별 분리** — 주거분↔주택용, 상업분↔일반용을 따로 맞춤(2차원 레이킹;
   건물통합 용도 조인 후 적용 예정, §8)
3. **감도분석** — 모든 하류 분석을 ⓐ무보정 ⓑ규율보정 ⓒ플래그제외 3벌로
   계산해 결론이 보정에 의존하지 않음을 보임. '버리기'는 ⓒ로 강등되어
   강건성 체크의 하나로 살아 있습니다.

## 7. 격자 수요지도 — 1단계의 본체

**스크립트**: `scripts/s1_grid_demand.py` → `out/public/s1_grid_demand_2024.csv.gz`

**방법**:
1. 에너지 2024년 12개월을 PNU별 연간 kWh로 합산 (155.7만 PNU, 211.81 TWh)
2. 지적 zip 17개에서 dbf(PNU)와 shp(도형)를 레코드 단위로 **나란히 스트리밍**
   — 같은 순서로 저장돼 있어 짝이 맞습니다. 에너지에 있는 필지만 골라
   **bbox(외접사각형) 중심점**을 좌표로 취함 (폴리곤 전체를 읽지 않아 빠름.
   필지는 작아 100m 격자에서 무해한 근사 — 메타파일에 명시)
3. 좌표 변환: EPSG:5186(지적 원본) → **5179**(분석 표준) — pyproj==3.8.0 고정.
   경위도 상태에서 거리·면적을 재지 않는다는 CRS 정책 그대로입니다.
4. 100m 격자 셀 = (floor(x/100), floor(y/100))에 kWh 누적 — ⓐⓑⓒ 3벌 동시에

**결과**: 점유 셀 672,690개. 합계 ⓐ 200.3 / ⓑ 212.6 / ⓒ 190.4 TWh.

**검산 사슬** (앞 절들과 맞물리는지): 연간 총량 211.81 = 월별 추이 합 ✓,
격자화 필지 149.7만/155.7만 = 96.1% = 조인율 ✓, ⓐ/총량 = 94.6% = 사용량

## 부록 B. 용어집 (쉬운 말로)

- **PNU**: 필지의 전국 유일 19자리 코드. 지번의 주민등록번호.
- **조인(join)**: 두 데이터를 공통 키(여기선 PNU)로 잇는 것.
- **커버리지**: 우리 데이터 합 ÷ 공표 통계. "전체의 몇 %를 담았나".
- **R²**: 두 변수가 함께 움직이는 정도(0~1). 로그 R²는 작은 시군구의
  발언권을 살려주는 버전.
- **레이킹**: 분포 모양은 두고 합계만 참값에 맞추는 비례 조정 (§6).
- **vintage**: 데이터의 기준 시점. 지적도 2024-12-04본처럼.
- **vintage 드리프트**: 시간이 지나며 기준 시점과 현실이 어긋나는 것.
- **플래그**: 의심스러워서 건드리지 않고 표시만 해둔 단위.
- **EPSG:5179 / 5186**: 좌표계 번호. 5179가 이 연구의 분석 표준.
- **bbox**: 도형을 감싸는 최소 사각형. 그 중심을 필지 위치의 근사로 씀.
