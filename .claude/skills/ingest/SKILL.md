# /ingest <경로> — 데이터 반입 루틴

사용자가 새로 받은 데이터를 파이프라인에 들이는 고정 절차. 인자가 없으면
`DATA_ROOT` 아래 최근 48시간 내 변경 파일을 찾아 후보를 제시하고 확인받는다.

## 절차 (순서 고정, 생략 금지)

1. **확인**: 경로·크기·형식·파일 수를 조회하고 무엇인지 사용자 설명과 대조.
2. **무결성 검증** (스크립트로 — 값을 눈으로 읽지 않는다):
   - zip이면 CRC 전수 검사, xlsx/csv면 구조(시트·헤더·행수) 덤프
   - 인코딩 확인(cp949/utf-8), 좌표계가 있으면 prj/메타 확인
   - 기존 보유분과 중복 여부(동일 장면·동일 표) 검사
3. **등록**:
   - 공간자료(gpkg·shp·tif·영상) → `config/layers.yml` + `validate_layers.py` 통과
   - 표형 자료 → `rdb/<통계명>/` 위치 확인 + `config/sources.yml` +
     `validate_sources.py` 통과
   - 등록 항목에는 origin(출처 URL·메뉴 경로), vintage, 취득일, 함정(note)을 기록
4. **명세 갱신**: `docs/data_provenance.md` §5(대기 자료) 또는 해당 절 갱신.
5. **보고**: 무엇이 들어왔고, 검증 결과, 바로 가능한 다음 분석 1~2개 제안.

## 멈춤 규칙

- 검증 실패(손상·건수 불일치·인코딩 깨짐) 시 등록하지 말고 원인 보고 후 중단.
- 기준년(2024) 밖 자료는 등록하되 note에 시점 플래그를 명기.
- 코드 매핑(행정구역 등)이 필요한데 사전에 없으면 멈추고 확인(CLAUDE.md).
