# /export-docs [키워드…] — 문서 Word 변환

`scripts/export_docs.py`를 venv 파이썬으로 실행한다.

- 인자 없음 → 전체(분석노트, 경제학개념QA, 변수데이터명세, GeoAI 논의록)
- 인자 있음 → 키워드 부분일치로 선택 (분석 / qa / 명세 / geoai)
- 기본 출력: `docs/word/` (git 추적됨 — 10MB 훅 한도 안)
- 사용자가 공유용 위치를 원하면 `--dest "D:\y06.워킹페이퍼\..."` 로 지정

실행 후 저장된 파일 경로를 보고하고, 변환 품질(표 깨짐 등)이 의심되면
해당 docx를 열어 확인하라고 안내한다. 변환 결과물은 산출물이므로 md 원본을
고치지 않는 한 재변환으로 항상 재생산 가능 — docx를 직접 편집하지 않는다.
