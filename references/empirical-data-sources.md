## 종합

막히는 데이터 없음. [2026-10-07 갱신] 최대 병목이던 건축물에너지가 건축HUB 공개
다운로드(필지 단위)로 해소 — 남은 절차는 ① 제주 정산가(KPX 문의) ② 표제부 단위
공문(선택) 정도. 세 숫자 모두 공개 자료만으로 1차 추정 가능.
해상도 판단: 분석의 병목 해상도는 154kV 권역(수십 km²)이므로 필지 단위(수백 m²)로
충분. 유일한 손실은 혼합용도 필지의 가구/기업 분해 — 대장 용도·계약종별 통계로 보정.
논문 표기는 "필지 단위 실측 집계(다동 필지는 합산)"로 정직하게.

## 건축물에너지 사용량 — 신청 사양 (갱신: 공개본은 지번 단위로 확보, 아래는 표제부 단위 공문 요청 시 기준)

모형이 비교정태·연간 총량 구조이므로 **단면 1개년이면 성립**하나, 연간 총계가
아닌 **월별**로 받아야 한다. 근거 셋:

1. **비건물 부하 식별**(제안서 과업): 가로등·농사용 등은 계약종별 × 월별 계절
   패턴 대조로만 구성 분해 가능. 연간 총계는 차액의 규모만 주고 구성을 못 가름.
2. **변전소 용량 정합성 검증**: 변전소 용량은 MW(피크), 사용량은 MWh(에너지).
   최대수요월 + 부하율 가정으로 피크를 근사해야 단위가 맞음.
3. **총량 검증 강화**: 한전 판매전력량이 월별 공표 → 12개 포인트 교차 검증.

| 항목 | 사양 |
|---|---|
| 기간 | 2024 + 2025 2개년 월별 (협의 1회 — 이상연도 체크용. 축소 시 최근 완결 1개년) |
| 에너지원 | 전기만 (신청 범위 최소화) |
| 단위 | 건물(건축물대장 표제부)별 × 월별 kWh |
| 필수 필드 | 관리건축물대장PK(매칭키), 지번/도로명주소, 주용도, 연면적 |
| 규모 | 약 730만 동 × 12개월 ≈ 1억 행 미만, 수 GB — 로컬 parquet 처리 가능 |
